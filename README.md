# NoDPI (Android)

Локальный HTTP/HTTPS-прокси на Kivy, который обходит DPI-блокировки: фрагментирует
TLS ClientHello (режим Disorder) по границе SNI.

## Режимы

- **Все сайты** — обход применяется ко всем TLS-соединениям.
- **Чёрный список** — только для доменов из списка.
- **Автоопределение** — сначала без обхода; если сервер не ответил, домен запоминается и соединение повторяется с обходом.

## Использование

1. Установите APK из Actions → последний запуск → Artifacts.
2. Оставьте включённым «VPN: весь трафик (без прокси)», нажмите «ЗАПУСТИТЬ ПРОКСИ» и
   подтвердите системный запрос VPN. Больше ничего настраивать не нужно — работает
   на Wi-Fi и в мобильной сети, для браузеров и приложений.
3. Без VPN (выключите переключатель) приложение работает как обычный HTTP-прокси
   `127.0.0.1:8881`, его нужно указать вручную в Wi-Fi/браузере.

## Как устроен VPN-режим

`NoDpiVpnService` поднимает TUN с маршрутом `0.0.0.0/0` и передаёт его Python-коду
(`tunnel.py`). TCP перенаправляется на локальный сервер движка (он видит настоящий
адрес и SNI и фрагментирует ClientHello), DNS обслуживается своим резолвером
(DoH без SNI и UDP DNS — обход подмены DNS), QUIC (UDP/443) отбивается, чтобы
приложения перешли на TCP, остальной UDP пробрасывается. IPv6 не маршрутизируется.

## Сборка

APK собирается GitHub Actions (`.github/workflows/build_apk.yml`) при пуше в `main`/`master`
или вручную (Run workflow). Версии подобраны вместе и менять их по отдельности не стоит:
python-for-android `v2024.01.21` = Python 3.11.5 + Kivy 2.3.0 + NDK 25b.

Файлы: `main.py` (приложение), `buildozer.spec`, `p4a_hook.py` (добавляет сервис в
манифест), `java_src/` (VPN-сервис).

Запуск на ПК для проверки: `pip install kivy && python main.py`.
