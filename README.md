# NoDPI (Android)

Локальный HTTP/HTTPS-прокси на Kivy, который обходит DPI-блокировки: фрагментирует
TLS ClientHello (режим Disorder) по границе SNI.

## Режимы

- **Все сайты** — обход применяется ко всем TLS-соединениям.
- **Чёрный список** — только для доменов из списка.
- **Автоопределение** — сначала без обхода; если сервер не ответил, домен запоминается и соединение повторяется с обходом.

## Использование

1. Установите APK из Actions → последний запуск → Artifacts.
2. Нажмите «ЗАПУСТИТЬ ПРОКСИ», разрешите VPN-подключение (переключатель
   «VPN: весь трафик» включён по умолчанию).
3. Всё: Wi-Fi и LTE, ничего прописывать не нужно. Весь IPv4-трафик устройства
   (браузеры, Telegram, приложения) идёт через движок, DNS-подмена обходится
   через DoH/UDP DNS, QUIC отбивается, чтобы приложения перешли на TCP.

Без VPN (переключатель выключен) работает как обычный HTTP-прокси
`127.0.0.1:8881`, который нужно указать в настройках сети.

Устройство VPN: `NoDpiVpnService` (TUN 10.111.222.1/24, маршрут 0.0.0.0/0),
пакеты разбирает `tunnel.py`: TCP заворачивается в локальный сервер ядра,
оригинальный адрес назначения берётся из таблицы потоков.

## Сборка

APK собирается GitHub Actions (`.github/workflows/build_apk.yml`) при пуше в `main`/`master`
или вручную (Run workflow). Версии подобраны вместе и менять их по отдельности не стоит:
python-for-android `v2024.01.21` = Python 3.11.5 + Kivy 2.3.0 + NDK 25b.

Файлы: `main.py` (приложение), `tunnel.py` (TUN-ретранслятор), `buildozer.spec`, `p4a_hook.py` (добавляет сервис в
манифест), `java_src/` (VPN-сервис).

Запуск на ПК для проверки: `pip install kivy && python main.py`.
